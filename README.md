# intonation-trainer-android
Android app to help train intonation. Targeted at players of string instruments, or other instruments where pitches can be played in a continuous interval (as opposed to descrete, e.g. piano)

The app prompts you with a target tone, and plays a frequency at a random point within +/- 1 semitone of the target. The user then adjusts the frequency until they think it matches the target and submits.
